# Anime World V5

مشروع Flutter كامل كبنية تطبيق مشاهدة أنمي:
- واجهة مختلفة عن Anime Slayer.
- أنمي وأفلام وصور وبيانات من Jikan.
- بحث ومفضلة.
- مواسم وحلقات مرتبة.
- لوحة محلية لإضافة روابط الحلقات.
- مشغل فيديو داخل التطبيق عبر video_player.
- دعم روابط HLS مثل m3u8.

تشغيل:
flutter clean
flutter pub get
flutter run

بناء APK:
flutter build apk --release

مهم: المشروع لا يتضمن روابط حلقات أو أفلام مقرصنة. أضف فقط روابط فيديو تملك حق بثها.
